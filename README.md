# Afterglow Cover Studio

[![Make GTA 6 Cover Art bounty](https://make.fun/badge/gta6-cover-art-01.svg)](https://make.fun/competitions/gta6-cover-art-01)
[![Rank](https://make.fun/badge/gta6-cover-art-01/Reyzz95/gta6-cover-art-01/rank.svg)](https://make.fun/competitions/gta6-cover-art-01)
[![Reward](https://make.fun/badge/gta6-cover-art-01/Reyzz95/gta6-cover-art-01/reward.svg)](https://make.fun/competitions/gta6-cover-art-01)

Afterglow turns your photos into neon sunset posters. Pick a hero layout, grid or triptych, give each panel a photo, and add a title and tagline. Export a square, portrait or wide PNG. Photos stay in your browser.

Open `app/index.html` in desktop Chrome, or run `node serve.ts` with Node 22 and open [the local studio](http://localhost:8080/). Add `?demo=1` to try the bundled samples. Drag a panel to pan and scroll over it to zoom.

To build the bounty dossier, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
